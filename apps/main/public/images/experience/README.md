# Experience Documentation Images

Add documentation photos for each experience here:

## Folder Structure:
- `bangkit/` - Bangkit Academy photos
- `lab-assistant/` - Laboratory Assistant documentation
- `teaching-assistant/` - Teaching Assistant photos

## Image Guidelines:
- Format: JPG or PNG
- Size: Recommended 800x600px or 4:3 aspect ratio
- File naming: descriptive names (e.g., `bangkit-team-photo.jpg`)
- Optimize images for web (compress to < 500KB each)

## Upload Instructions:
1. Create folders for each experience
2. Add 3-5 photos per experience
3. Update the portfolio.js file to include image references
4. Photos will automatically display in the timeline

## Example structure:
```
experience/
├── bangkit/
│   ├── team-photo.jpg
│   ├── capstone-presentation.jpg
│   └── learning-session.jpg
├── lab-assistant/
│   ├── lab-session.jpg
│   └── student-mentoring.jpg
└── teaching-assistant/
    ├── classroom.jpg
    └── consultation.jpg
```
